3. WORKING DAYS
   Exclude: ALL Sundays
   Exclude: ALTERNATE Saturdays (every other Saturday)
   Include: Monday-Friday always

   IN-HOUSE: 19 days (July 1-23)
   CONTRACTUAL: 20 days (July 1-23)

   Function: count_working_days_inhouse() and count_working_days_contractual()

4. STATUS CALCULATION (Multi-Factor Rubric)

   PRIMARY: Utilization %
   ├─ < 50%      → CRITICAL (underbooked)
   ├─ 50-95%     → Check secondary factors
   └─ > 95%      → OPTIMAL if good QA, else HIGH

   SECONDARY: Improvement (IN-HOUSE MC only) + QA
   ├─ If QA < 60 AND Improvement < 30 → CRITICAL
   ├─ If well-booked AND QA ≥ 80 AND Improvement ≥ 40 → OPTIMAL
   └─ Otherwise → HIGH

   QA NULL/0: If util < 50% → CRITICAL, else → NA

5. APPOINTMENT STATUS FILTER
   EXCLUDE ONLY: CANCELLED, ANC
   INCLUDE: All others (COM, BOOKED, ACT, WIC, RES, etc.)

6. FORECAST 7-DAY
   = total_appts_in_period / working_days_in_period
   = Daily rate (past trend used to forecast future)

   Example: Sweta 323 appts / 19 days = 17/day
